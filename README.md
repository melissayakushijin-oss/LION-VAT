# LION VAT

Ferramenta em Excel que reúne as informações para a declaração do Imposto de Renda Pessoa Física (IRPF), em um passo a passo guiado com menu lateral e botões de navegação.

## Etapas

1. **Titular:** nome, CPF, nascimento, título de eleitor, cônjuge, endereço, contatos, alterações em relação à entrega anterior e residência no exterior.
2. **Informes:** banco, valor atual e anexo de até três bancos, com total somado automaticamente.
3. **Notas:** tabela das entradas mês a mês (data, categoria e valor), com filtros.

## Como usar

1. Baixe a planilha e abra no Microsoft Excel para Windows.
2. Se aparecer um aviso de segurança, clique em **Habilitar Conteúdo**.
3. Preencha as telas em ordem, usando **Próximo >** e **< Anterior**.
4. Use os dados reunidos na declaração, no programa oficial da Receita Federal.

## Privacidade

Os dados ficam só no seu computador. Não envie para este repositório uma planilha preenchida com dados reais; para testes, use dados fictícios.

## Aviso

Ferramenta auxiliar de organização, sem vínculo com a Receita Federal. Ela não transmite a declaração, e a conferência e a entrega são de responsabilidade do contribuinte.
